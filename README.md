# Student Management System

A responsive Student Management System built using HTML, CSS, and JavaScript. It allows users to manage student records, track attendance, and monitor student statistics through a dashboard.

## Features

### 1. Student Management
- Add new students.
- Edit existing student details.
- Delete student records.
- Form validation.
- Prevent duplicate roll numbers.

### 2. Search & Sorting
- Search students by name or roll number.
- Sort students by name (A to Z).
- Sort students by name (Z to A).
- Sort by roll number (Low to High).
- Sort by roll number (High to Low).

### 3. Attendance Management
- Mark students as Present.
- Mark students as Absent.
- Update attendance status.
- Prevent duplicate attendance records for the same student on the same date.
- Save attendance records in LocalStorage.

### 4. Dashboard
- Display total students.
- Display present students.
- Display absent students.
- Display total courses.
- Automatically update dashboard statistics.

### 5. Data Storage
- Store student records using Browser LocalStorage.
- Store attendance records using Browser LocalStorage.
- Maintain data after page refresh.

### 6. User Interface
- Black and White theme.
- Responsive dashboard layout.
- Interactive buttons with hover effects.
- Responsive student management form.
- Clean student data table.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git & GitHub

## How to Run the Project

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Start managing student records.
